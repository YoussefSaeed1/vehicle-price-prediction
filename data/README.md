# Data

`data.csv` is the **Car Features and MSRP** dataset published on Kaggle by Cooper Union:
https://www.kaggle.com/datasets/cooperunion/cardataset

11,914 rows, 16 columns. Scraped from Edmunds and Twitter in 2017. Prices are US MSRP in USD.

| Column | Description |
|---|---|
| Make / Model | Manufacturer and model name |
| Year | Model year (1990–2017) |
| Engine Fuel Type, Engine HP, Engine Cylinders | Powertrain |
| Transmission Type, Driven_Wheels | Drivetrain |
| Number of Doors, Vehicle Size, Vehicle Style | Body |
| Market Category | Comma-separated tags, e.g. `Luxury,High-Performance` |
| highway MPG, city mpg | Fuel economy |
| Popularity | Twitter-based popularity score (one value per make) |
| MSRP | Target: Manufacturer's Suggested Retail Price |
